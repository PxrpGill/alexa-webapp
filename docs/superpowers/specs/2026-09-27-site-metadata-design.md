# Мета-информация сайта: единый SEO-слой

Дата: 2026-09-27
Статус: согласовано, готово к планированию

## Задача

Привести мета-информацию сайта клиники «Алекса» в полный и согласованный вид:
уникальные title/description на всех страницах, канонические адреса, Open Graph,
карта сайта, robots и микроразметка организации.

## Исходное состояние

Метаданные заданы на 12 из 38 страниц. Остальные 26 наследуют корневой fallback
`GENERAL_META = { title: 'Алекса', description: 'Алекса' }`, то есть попадают
в выдачу с пустым по смыслу заголовком.

Дефекты, зафиксированные при аудите:

| # | Проблема | Место |
|---|---|---|
| 1 | `<html lang="en">` на русскоязычном сайте | `app/layout.tsx:23` |
| 2 | Нет `metadataBase` — относительные OG/canonical не резолвятся | `app/layout.tsx` |
| 3 | Нет `openGraph` и `twitter` ни на одной странице | все |
| 4 | Нет canonical при 17 постоянных редиректах с легаси-URL | все |
| 5 | Нет `robots.ts` и `sitemap.ts` | `app/` |
| 6 | Нет JSON-LD организации и филиалов | — |
| 7 | Одинаковый description на `gnatologiya`, `parodontologiya`, `gigiena-i-profilaktika-vz` | 3 файла |
| 8 | У `ortodontiya-vz` description описывает ортопедию (виниры, коронки, протезы) | `ortodontiya-vz/page.tsx` |
| 9 | Хвостовой пробел в description | `ortopediya-vz/page.tsx` |
| 10 | Разнобой префиксов title, нет `title.template` | 12 файлов |
| 11 | `site.webmanifest` ссылается на `/android-chrome-*.png`, файлы лежат в `/favicon/` | `public/favicon/site.webmanifest` |
| 12 | `generateMetadata` без типа `Metadata` | 12 файлов |

Отдельно: `app/landyshevaya/page.tsx` недостижима — `next.config.mjs:38`
редиректит `/landyshevaya` на `/`. В реестр и sitemap не включается.

## Решения

Домен: `https://aleksa-dent.ru` (найден в `views/privacy-policy-page/models/privacy-policy-page.constants.ts:15`,
единственное упоминание в репозитории). Выносится в `SITE_URL`
с переопределением через `NEXT_PUBLIC_SITE_URL`.

Гео-привязка: «Ростов-на-Дону» на всех страницах. Юридический адрес ООО «Алекса» —
Ростов-на-Дону, ул. Волкова, 22; филиал в п. Янтарный находится в 8 км от города.
Точные адреса обоих филиалов уходят в JSON-LD.

OG-картинка: генерация через `next/og` (`ImageResponse`).

Микроразметка: `Dentist` с двумя `LocalBusiness`-филиалами в корне, `Article`
на статьях блога. `BreadcrumbList` и `FAQPage` отложены.

### Контракт хелпера

```ts
export const buildMetadata = (
    route: SiteRoute,
    overrides?: Partial<PageMeta>,
): Metadata;
```

`SiteRoute` типизируется как `(typeof SITE_NAVIGATION)[keyof typeof SITE_NAVIGATION]`,
поэтому опечатка в пути падает на `tsc --noEmit`, а не в проде.

Хелпер возвращает `title`, `description`, `alternates.canonical` (относительный путь),
`openGraph` (`title`, `description`, `url`, `type`) и `robots`, если он задан в записи реестра.
`overrides` нужны динамическим страницам, где текст приходит из API.

Использование на статической странице — одна строка:

```ts
export const metadata = buildMetadata(SITE_NAVIGATION.price);
```

### Корневой layout

```ts
export const metadata: Metadata = {
    metadataBase: new URL(SITE_URL),
    title: {
        default: 'Семейная стоматология «Алекса» в Ростове-на-Дону',
        template: '%s | Стоматология «Алекса»',
    },
    description: DEFAULT_DESCRIPTION,
    alternates: { canonical: '/' },
    openGraph: {
        type: 'website',
        locale: 'ru_RU',
        siteName: 'Стоматология «Алекса»',
        url: '/',
    },
    robots: { index: true, follow: true },
    formatDetection: { telephone: false },
};
```

Главная страница использует `title.absolute`, чтобы суффикс шаблона не задвоился.

## Правила копирайта

- **Title**: содержательная часть не длиннее 36 символов — суффикс шаблона
  ` | Стоматология «Алекса»` занимает 24 из ~60 видимых в выдаче.
  Гео добавляется, только если вписывается в лимит.
- **Description**: 140–160 символов, законченное предложение,
  «что делаем → чем отличается → мягкий CTA». Уникальный на каждой странице.
- Без превосходных степеней и без обещаний результата лечения — требование
  38-ФЗ «О рекламе» к медицинской тематике.
- Без HTML-сущностей (`&nbsp;`, `&mdash;`): в отличие от контентных констант,
  метаданные попадают в `<meta>` как есть и отрендерятся текстом.
- `keywords` не используется.

## Динамические страницы

`/blog/[slug]` — `async generateMetadata`: title и description из ответа
`getSingleNews(slug)`. Фетчер глотает ошибки и возвращает `undefined`, поэтому
при отсутствии данных отдаём запись реестра для `/blog`. Дополнительно —
JSON-LD `Article` и `openGraph.type: 'article'`.

`/vakansii/[slug]` — то же на базе `getDetailVacancy({ vacancySlug })`,
фолбэк на запись `/vakansii`.

## Инфраструктура

### `app/sitemap.ts`

Статические маршруты берутся из `page-meta.constants.ts` — реестр остаётся
единственным источником истины. Динамические дописываются через `getAllNews()`
и `getAvailableVacancies()`; оба фетчера могут вернуть `undefined`, поэтому
их результат обязателен к проверке — при недоступном бэкенде отдаём статическую
часть, а не роняем маршрут. Исключаются `/letter` и `/landyshevaya`.
Собственный `revalidate = 3600`.

### `app/robots.ts`

`allow: '/'`, `disallow: ['/letter', '/api/']`, ссылка на `${SITE_URL}/sitemap.xml`.
Генерируется из TS, статических файлов в `public/` не заводим.

### JSON-LD

`shared/config/seo/organization.ts` собирает схему `Dentist` с
`department: [LocalBusiness, LocalBusiness]`. Адреса, координаты, телефоны
и режим работы переиспользуются из `YANDEX_MAP_INFO_CARD` и `MOBILE_PHONE`
в `shared/config/global-constants.constants.ts` — дублировать их нельзя,
иначе данные разойдутся. Реквизиты (ООО «Алекса», ОГРН 1096193002597,
ИНН 6161055650, oooalexa@bk.ru) берутся из
`views/details-page/models/details-page.constants.ts`. Скрипт вставляется
в корневой layout.

### `app/opengraph-image.tsx`

`ImageResponse` 1200×630: фон `#183826` (`--color-green-4`), логотип,
title страницы, домен внизу.

`ImageResponse` не принимает woff2, а Involve в проекте есть только в woff2.
Подготовка шрифта — разовая, результат коммитится:

```bash
python3 -m pip install --user fonttools brotli
python3 -c "
from fontTools.ttLib import TTFont
from fontTools.subset import Subsetter
f = TTFont('src/public/fonts/Involve-SemiBold.woff2')
f.flavor = None
s = Subsetter()
s.populate(unicodes=list(range(0x20, 0x7F)) + list(range(0x400, 0x500)) + [0x2014, 0x2116, 0xAB, 0xBB])
s.subset(f)
f.save('src/shared/config/seo/fonts/Involve-SemiBold-subset.ttf')
"
```

Проверено: исходный шрифт содержит 134 кириллических глифа, полный TTF — 118 КБ.
Шрифт кладётся в `shared/config/seo/fonts/`, а не в `public/` — он нужен только
серверному рендеру.

## Верификация

Тестового фреймворка в проекте нет, поэтому проверка — сборка и фактический вывод:

1. `tsc --noEmit` — типизация ключей реестра ловит опечатки в путях.
2. `pnpm build` — падает при сломанном `generateMetadata` или `sitemap.ts`.
3. Скрипт обхода: `pnpm start`, запрос всех 37 живых URL, извлечение `<title>`,
   `og:*`, `canonical`. Проверяется: нет заглушки «Алекса», нет дублей
   description, длины в пределах 50–60 и 140–160. Результат — таблица.
4. Ручная проверка `/sitemap.xml`, `/robots.txt`, `/opengraph-image`.
5. `pnpm lint` только на затронутых файлах — репо-широкий форматтер запускать нельзя.

## Риски

- **Домен.** `https://aleksa-dent.ru` подтверждён единственным упоминанием
  в коде. Если прод на другом домене, `metadataBase` и canonical укажут не туда.
  Снимается переменной `NEXT_PUBLIC_SITE_URL`.
- **Номер лицензии.** В `documents-and-licenses.constants.ts` номер лицензии
